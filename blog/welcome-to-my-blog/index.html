Why I Built This Site

I wanted a simple, maintainable way to publish content online. After evaluating various options, I decided to build a static site generator using:

  • Flask for the development experience
  • Frozen-Flask for static site generation
  • Markdown for content authoring
  • GitHub Actions for automated deployment

The Benefits of Static Sites

Static sites offer several advantages:

  1. Fast: No server-side processing means instant page loads
  2. Secure: No database or server-side code to exploit
  3. Cheap: Can be hosted for free on platforms like GitHub Pages or Netlify
  4. Reliable: Simple architecture means fewer things can break
